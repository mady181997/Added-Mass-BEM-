The above code computes the 6 x 6 added mass matrix using boundary element method and has been optimised for speed and space complexity using bsxfun and uses collocation method for computation.
1. Download the stl file from any cad software.
2. upload and mesh in gmsh software and use refinement for better mesh and accurate results.
3. Download again as stl file from gmsh and in option leave as ascii and select per physical surface option during chekout.
4. Run the main file and select the stl file.
5. The coordinate system is needed and can be changed in main mode.
6. The vertex is scaled to meters for reliable results.
